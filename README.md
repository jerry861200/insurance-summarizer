# Insurance Document Summarizer

> **Status: Under construction.** Full README, design rationale, and demo instructions land in Phase D.

A FastAPI service that ingests insurance policy PDFs, extracts structured fields (policy number, insured name, dates, premium, coverage, exclusions), and produces a human-readable Markdown summary.

Built as a take-home case study. See [`docs/design_rationale.md`](docs/design_rationale.md) for the full design discussion (once it exists).
